# طرح‌یار (TarhYar)

کوپایلوت هوشمند طراحی و بررسی ضوابط معماری برای دفاتر طراحی ایران.
مخاطب: دفاتر معماری و شرکت‌های طراحی-ساخت در تهران.
پوزیشنینگ: کوپایلوت ضوابط و طراحی (نه یک گالری نمونه‌کار).

**ریپازیتوری:** [github.com/massoudsh/tarhyar](https://github.com/massoudsh/tarhyar)

## اجرای رابط کاربری

```bash
cd web && npm install && npm run dev
```

آدرس [http://localhost:3000](http://localhost:3000) را باز کنید. چیدمان راست‌به‌چپ فارسی، سیستم طراحی (سفید گرم، زغالی، زیتونی/برنزی)، صفحه اصلی با هیرو، خدمات، پروژه‌های منتخب، بلوک اعتبار و CTA.

**پشته فنی (MVP):** Next.js (App Router)، TailwindCSS، Framer Motion (حداقلی)، داده استاتیک، آروان‌کلود (Docker/Container + CDN).

**دامنه:** صفحه اصلی، پروژه‌ها، جزئیات پروژه، خدمات، درباره ما، تماس. بدون بلاگ، بدون حساب کاربری.

فرم تماس از Resend استفاده می‌کند. قبل از استقرار، `web/.env.example` را به `web/.env.local` کپی کنید و مقادیر `RESEND_API_KEY`، `CONTACT_TO_EMAIL` و `CONTACT_FROM_EMAIL` را تنظیم کنید. بدون این متغیرها، ارسال فرم با خطای پیکربندی متوقف می‌شود و موفق گزارش نمی‌شود.

## استقرار (آروان‌کلود)

اپلیکیشن برای پلتفرم Container/PaaS آروان‌کلود کانتینری شده است (`web/Dockerfile`، خروجی standalone نکست‌جی‌اس). برای مراحل ساخت و استقرار به [DEPLOY.md](./DEPLOY.md) مراجعه کنید.
